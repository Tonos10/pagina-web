# Azteca Thai Boxing Web

Sitio web estático para Azteca Thai Boxing con páginas informativas y de pago en línea.

## Sitio en producción

El sitio está publicado en:

- https://aztecathaiboxing.com/index.html

## Estructura del proyecto

- `index.html`: página principal.
- `paquetes.html`: información de paquetes.
- `pago-en-linea.html`: flujo de pago en línea.
- `pagos/`: recursos y archivos relacionados con pagos.
- `css/`: estilos del sitio.
- `js/`: scripts del frontend.
- `assets/`: imágenes y otros recursos estáticos.

## Ejecutar localmente

Como es un sitio estático, puedes abrir `index.html` directamente en tu navegador.

Si prefieres servirlo con un servidor local:

```powershell
python -m http.server 8000
```

Luego abre `http://localhost:8000`.
